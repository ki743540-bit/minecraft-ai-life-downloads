# Minecraft AI LIFE 配布ファイル

AndroidのMinecraft統合版向け、無料のオフライン会話アドオンです。会話は定型応答であり、生成AIではありません。

## ダウンロード

- [まずはこちら：Behavior Pack（.mcpack）](Minecraft-AI-LIFE-BP-0.1.0.mcpack?raw=true)
- [アドオン形式（.mcaddon）](Minecraft-AI-LIFE-0.1.0.mcaddon?raw=true)

対応下限はMinecraft Bedrock 1.21.90です。Android実機での取り込み・動作は確認中です。

ファイルを保存し、Minecraftで開いてください。「インポート成功」が出たら、コピーしたワールドのビヘイビアーパックでMinecraft AI LIFEを有効にします。本1個と棒1本で「対話の手帳」を作れます。

豚・エンダーマン・村人の個性、感情、記憶と日本語会話を実装しています。独自の自律移動、モブ同士の会話・恋愛、外部生成AIへの接続は未実装です。

SHA256SUMSはファイルの照合用です。ZIP構造とファイル内容は検査済みですが、Minecraft実機での動作確認とは区別しています。
